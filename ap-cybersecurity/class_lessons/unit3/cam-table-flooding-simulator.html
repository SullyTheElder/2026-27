Before you start

This is a simulation. No real switch or network is involved.

You're looking at a fictional office switch for Meridian Analytics. It has 16 ports and a MAC address table with room for only 8 entries. You'll watch it work normally, then flood it, then act as the eavesdropping adversary.

Takeaways

MAC flooding fills a switch's address table with falsified MAC addresses until there's no room left to learn real ones. The switch fails open into broadcast mode, sending every frame out every port. That lets an adversary eavesdrop (sniff) on traffic that was never meant for them.
