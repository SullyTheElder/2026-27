Concept: Four Ways a SOHO Network Gets Exposed

Match these back to what you found in the panel above — you likely already flagged examples of every category.

  • Default configurations. Routers and access points shipped with widely known default usernames, passwords, or settings let anyone who recognizes the defaults get in and change things.
  • Outdated firmware. A device that hasn't been updated is missing security patches for vulnerabilities that are often publicly known — leaving it open to compromise or malware.
  • Unmonitored or unknown devices. A device on the network that nobody recognizes could be an intruder who's already gotten in.
  • Insecure IoT devices. Smart devices (thermostats, cameras) are often weakly secured. If they share a network with trusted devices, an attacker who compromises one can move laterally to reach the others.

Vocabulary

  • Vulnerability — a weakness in a device or network's configuration that could be exploited.
  • Default credentials — the username/password a device ships with, before an owner changes them.
  • Firmware — the built-in software that runs a device like a router; needs updates just like an OS.
  • WPS (Wi-Fi Protected Setup) — a convenience feature for connecting devices quickly that is also a known weak point attackers can target.
  • Lateral movement — an attacker using one compromised device to reach others on the same network.
  • Guest network isolation — keeping visitor or untrusted devices on a separate network from trusted devices and data.
