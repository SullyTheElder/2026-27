2 Internal Wi-Fi First about 8 min

Goal: set up and secure the staff network, and make sure it works before adding anything else.

  1. Open the Internal Wi-Fi tab.
  2. Give the network a new SSID (not the factory name).
  3. Choose a modern security type and a strong password (make one up).
  4. Turn off WPS. Then press Save.
  5. Press Check my settings and fix anything marked with an ✘.

      Concept: Guest and Internal Wi-Fi

      • Most access points let you create a guest network that gives internet access without access to the internal network. That adds a layer of protection for the main network.
      • Configure the internal network first and check that it works. That means a strong password, WPA2 or WPA3 encryption, and WPS disabled.
      • You reach these settings by typing the router or access point's address into a web browser and logging in with the administrator credentials.
      • The guest network is set up like any other wireless network: its own SSID, a strong password, and WPA2 or WPA3.
      • Extra guest protections include limiting the number of devices, blocking access to the internal network, setting access hours or session time limits, and a captive portal where users log in and agree to terms.
      • To verify a guest network, connect a device to it. It should reach the internet but not the internal resources.

      Vocabulary

      WPA2 / WPA3
      Modern encryption standards that protect what travels over a Wi-Fi network.
      WPS
      A quick-connect feature for Wi-Fi. It is usually disabled because it can be abused to get in.
      Guest network
      A separate Wi-Fi network for visitors, with internet access and no access to internal resources.
      Administrator credentials
      The user name and password that let someone change a device's settings.
      Captive portal
      A page guests must log in to or accept before they can use the network.
      Session limit
      A cap on how long a guest can stay connected.
