Concept: How Data Choose a Road

Before a device sends data, it puts a header on the packet with the source address and the destination address. Then it compares its own IP address and subnet mask with the destination address.

  • Same network segment: the data go straight to the destination through the switch. The router is never involved (your Trip A).
  • Different network segment: the data go to the default gateway, which is the router. The router sends them on toward the right segment (your Trip B).

A segmented network divides devices into groups to improve performance, management, and security. Each segment has its own range of addresses.

Vocabulary

Network segment
A group of devices set apart from others, with its own range of IP addresses.
Segmented network
A network divided into segments to improve performance, management, and security.
Packet header
The front part of a packet. It holds the source and destination addresses, plus other routing information.
Subnet mask
Numbers that tell a device which part of an address identifies the network.
Default gateway
The router address a device uses when the destination is on a different segment.
Router
A device that connects segments and forwards packets between them.
