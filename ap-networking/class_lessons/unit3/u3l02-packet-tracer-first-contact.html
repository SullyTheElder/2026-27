The Situation

Last class you planned the Bulldog Esports Invitational network on paper: which devices, wired or wireless, and how many switch ports. Now it's setup day, and you're going to build a scale model of that network in Cisco Packet Tracer.

Packet Tracer is a network simulator. You build devices and cables on the screen, give them settings, and test them, all without touching real equipment. That means you're allowed to break things. In fact, today you'll break something on purpose, and then fix it.

Scale model rule: you can't place 150 devices in 50 minutes, so one device stands in for each group from your U3L01 plan.

Packet Tracer's menus can look a little different from one version to the next. If something isn't exactly where this guide says, look around the same area. If you're still stuck, ask.

A quick tour of the screen

  • The big blank area in the middle is the workspace. You build here.
  • The panel along the bottom-left is the device palette. Pick a category first, then pick a model.
  • In the bottom-right corner you can switch between Realtime and Simulation modes. You'll use Simulation in Mission 6.
Stuck?It's a big program running on a remote computer, so the first launch can be slow. Give it a minute or two. If nothing appears after that, raise your hand.

3 Read the Lights about 5 min

Goal: get a green link light at both ends of every cable.

Look at the small dot at each end of each cable. Back in Unit 2 you learned what red, orange, and unlit lights mean on real equipment. This is the same idea.

Green: the link is up Amber/orange: a switch port is getting ready. Wait a bit. Red: no link. Something is wrong.

Wait about 30 seconds, or use the fast forward time button near the bottom-left of the screen, until the amber lights settle. Any red lights left? Fix them before moving on.

If you had a red light, what did you do to fix it?

Hint 1Is the red light on the router's end only, or on both ends?
Hint 2Routers ship with their ports turned off. Click the router, open its Config tab, pick the port the switch is plugged into, and look for the port status setting.

5 Prove It Works, Then Break It about 10 min

Goal: use ping to test the network, then cause and fix a problem.

Part A: Test. From Player 1's Command Prompt, ping each target by typing ping, a space, and the address. Record what happens.

From Player 1 to…AddressResult (replies or no replies?)
Gateway192.168.1.1
Tournament Server192.168.1.100

The very first ping on a new network sometimes gets no reply while the devices get introduced to each other. Run it again before you decide something is broken.

Part B: Break it on purpose.

  1. On Player 2, change the IP address to 192.168.5.12. Leave everything else alone.
  2. From Player 2, ping the Tournament Server (192.168.1.100). What happens?
  3. Fix Player 2 so the ping works again.

6 Watch a Packet Travel about 5 min

Goal: see data move through your network, one step at a time.

  1. Switch to Simulation mode (bottom-right corner).
  2. In the right-hand toolbar, pick Add Simple PDU (it looks like a closed envelope). Click Player 1, then click the Tournament Server.
  3. Use the Capture / Forward button in the simulation panel to step the packet forward, and watch the envelope.
  4. Switch back to Realtime mode when you're done.

Predict, then check: which devices did the packet pass through, and did it go to the router? Why do you think that is?

Vocabulary

Now that you've done it, here are the names for what you used.

Network simulator
Software that lets you build and test a pretend network on a screen.
Link light
A small light at each end of a cable showing whether the connection is working.
Static IP address
An address you type in by hand instead of having a device receive one automatically.
Subnet mask
Numbers that tell a device which part of an address identifies the network.
Default gateway
The router address a device uses to reach devices on other networks.
Ping
A test that sends a small message to another device and reports whether it answers.
Simulation mode
A view that slows data down so you can watch each packet's trip.
