Be the Router: Reading a Routing Table

How a router decides where each packet goes — CB 3.2.A.3 (activity first, concept after)

The Situation

Last class you watched a packet skip the router, and another one go through it. Today you are the router. The Bulldog Esports Invitational network has grown: the gym LAN, a new Spectator Wi-Fi segment, and the pretend internet, all meeting at one router with three ports.

The router's own address on each segment ends in .1. All three segments use the mask 255.255.255.0, so the first three numbers of an address tell you which segment it is on.

Concept: The Routing Table

The cheat sheet you wrote is what a router really has. A routing table lists the possible routes that packets can travel, one entry for each network the router knows how to reach.

  1. A packet arrives at the router.
  2. The router compares the packet's destination address with the entries in its routing table.
  3. The matching entry tells the router which segment the packet should go to.
  4. The router forwards the packet out of the right port, through the switch on that segment, to the destination device.

Notice what the router does not do: packets between two devices on the same segment (like your packet A) never reach it.

Vocabulary

Routing table
A list kept by a router showing the possible routes packets can travel.
Route (entry)
One row in a routing table: a network, and where to send packets headed for it.
Destination address
The address in a packet's header showing where the packet is going.
Port (interface)
A connection on the router that leads to one segment.
Forward
To pass a packet along toward its destination.
