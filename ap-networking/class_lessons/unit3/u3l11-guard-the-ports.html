4 The Flood Test about 10 min

Goal: see what a flood of fake addresses does to an unprotected switch, and how port security stops it.

A switch remembers addresses in a limited-size table. Someone who sends thousands of fake addresses can overflow it. This is a test you run on your own switch to learn how to defend it.

  1. Click port 9 (nothing is plugged in, and security is off). Press Run a flood test on this port. Read the result, then open the Address Table tab and look at the bar.
  2. Press Clear the fake entries on the Address Table tab.
  3. On port 9, turn port security on and choose any addresses, up to a maximum number. Set the maximum to 2. Run the flood test again.

        Concept: MAC Filtering and Port Security

        • MAC filtering restricts access by allowing only approved MAC addresses. A switch port can be set to permit a limited, specific set of addresses, and every other address is refused.
        • Limiting the number and range of addresses on a physical switch port can stop unauthorized devices from physically connecting to the network.
        • The same limits can also prevent MAC flooding. This happens when a switch receives so many different addresses that its address table overflows. A switch with a full table can start sending traffic out every port, so port security keeps the table from filling.

        Notice the trade-off from Mission 5: every new or replacement device has to be approved first. And because a MAC address can be copied, filtering is one layer of protection and not the whole answer. Next, you'll look at firewalls, which control traffic between networks.

        Vocabulary

        MAC address
        A hardware address that identifies a network device on its local network.
        MAC filtering
        Allowing only approved MAC addresses to connect.
        Port security
        Settings on a switch port that limit which addresses, and how many, may use it.
        Allowed list
        The set of addresses a port will accept.
        Address table
        The switch's memory of which MAC address is on which port.
        MAC flooding
        Overflowing a switch's address table with many fake addresses so it sends traffic out every port.
        Violation
        When a device breaks a port's rules. The port shuts down.
