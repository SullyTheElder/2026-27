2 Build It about 8 min

Goal: place and connect the devices in a new file.

  1. Open Packet Tracer and start a new, empty file. Save it as LastName_U3L06.
  2. Place and rename: 1 router (Gateway), 1 switch (Gym-Switch), 1 server (Tournament Server), and 4 PCs (Player 1, Player 2, Caster, Admin).
  3. Connect every PC and the server to the switch, and the switch to the router, using the automatic cable tool.

3 Configure the Fixed Devices about 12 min

Goal: set up the router, the switch, and the server, exactly as your blueprint says.

  1. Router: in the Config tab, pick the port connected to the switch. Turn the port on, and enter 192.168.1.1 with mask 255.255.255.0. The router is now the default gateway for the LAN.
  2. Switch: in the Config tab, look for the switch's management interface (it is often called VLAN 1). Turn it on, and enter 192.168.1.2 with mask 255.255.255.0. This is how an admin could reach the switch.
  3. Server, fixed address: open the server's settings and set a static address of 192.168.1.10, mask 255.255.255.0, default gateway 192.168.1.1.
  4. Server, DHCP: on the server, open the Services tab and choose DHCP. Turn the service on, then enter: default gateway 192.168.1.1, the pool start address and maximum users from your blueprint, and mask 255.255.255.0. Save it.

6 Break It, Fix It about 8 min

Goal: plant a fault in your partner's network and troubleshoot one in yours.

Pick one fault from this menu and plant it in your partner's file while they look away. Then swap.

  • Turn off the router port that connects to the switch.
  • Set one PC to a static address on the wrong network, like 192.168.5.20.
  • Turn off the DHCP service on the server, then flip one PC to a static address and back to DHCP so it asks again.

The troubleshooter uses ping, ipconfig, and the link lights to find the fault, then fixes it.

Concept: Configuring a LAN

You just followed the order a real network crew follows:

  1. Design first. Identify the devices, cabling, and settings the network needs before connecting anything.
  2. Connect the devices and cables, and label cables so they're easy to trace.
  3. Configure the infrastructure. A switch gets settings such as a password, address, and subnet mask, through its command line or its graphical interface, or through a management console reached by a console cable. The router is given an address and mask so it can act as the default gateway to other networks, including the internet.
  4. Configure the endpoints. Each device needs an address and subnet mask, either set by hand (static) or handed out automatically (DHCP).
  5. Verify. Use ping, which sends ICMP messages to an address. If the target is connected, it replies.

On real hardware, crews also need tools like a cable stripper, RJ45 connectors, a crimping tool, cable management gear, and safety glasses and gloves. You'll meet those later.

Vocabulary

Static address
An address entered by hand and kept fixed.
DHCP
A service that hands out addresses and other settings to devices automatically.
Address pool
The range of addresses a DHCP service is allowed to hand out.
Default gateway
The router address devices use to reach other networks, including the internet.
Management address
An address given to a switch so an administrator can reach and configure it.
Console cable
A cable that connects a computer directly to a device's management console.
Ping / ICMP
A test that sends ICMP messages to an address. A connected device replies.
