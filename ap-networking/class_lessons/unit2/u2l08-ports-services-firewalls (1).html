Concept: Ports, Services, and What Firewalls Actually Do

  • A port is a numbered channel (0–65535) that, paired with an IP address, tells a device which service a piece of traffic is meant for.
  • A service is software sitting on a machine, listening on a specific port, waiting for connections — a web server, a file-sharing service, a remote login tool.
  • A firewall doesn't simply block or allow everything — it applies rules, most commonly based on port number, IP address, and protocol, to decide what traffic is permitted.
  • Tie it back: when the firewall was in its more restrictive state, which services you found via netstat would have been reachable from another machine — and which wouldn't?

Vocabulary

  • Port — a numbered logical channel used to direct traffic to a specific service on a device.
  • Service — software listening on a port for incoming connections.
  • Firewall — a device or software that filters network traffic according to a rule set.
  • Segmentation — dividing a network into separate zones so groups of devices are isolated from one another.
  • Listening — the state of a port when a service is actively waiting for connections on it.
  • netstat / ss — command-line tools that list active network connections and listening ports on a machine.
