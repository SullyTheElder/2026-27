What You're Doing

You've calculated subnet sizes (U2L01–02) and configured a single device's address (U2L06). Now you'll configure a router that connects two separate subnets — giving each interface the correct address, and making sure devices on each side can reach each other.

This lab runs across two days: Friday is a guided walkthrough where we build a simple version together. Monday, you'll apply the same method to a new scenario on your own.

Step 3 — Build it in Filius

  1. Place one PC in Building A and one PC in Building B, plus one router connecting them.
  2. Configure the router's two interfaces using the first usable address in each block.
  3. Configure each PC with an address from its building's range, the correct mask, and the router interface as its gateway.
  4. Test: ping across buildings (the Building A device to the Building B device). Fix anything that fails.

Finished with time to spare? Add a second PC to each building (next address in the usable range) and confirm it can also ping across buildings — optional, but good practice.
