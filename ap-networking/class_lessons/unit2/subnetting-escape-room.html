Work as a team. When you’re done, use the “Download as PDF” button to save one copy for your team to turn in.

The Mission

The network closet door has locked behind you. To get out, your team has to crack the code on each room’s lock. Every code is a number that comes straight from the math you’ve been practicing — sizing subnets, finding network and broadcast addresses, and deciding whether devices share a subnet.

Tools you already have: block size = 2host bits; usable hosts = 2n − 2; the network address is the first address in the block and the broadcast address is the last.

Enter a code and press Try it to see whether the lock opens. Rooms can be solved in any order. Room 4 is a bonus — the escape counts once Rooms 1, 2, 3, and the Final Room are open.
