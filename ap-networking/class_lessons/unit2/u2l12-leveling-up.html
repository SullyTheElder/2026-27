Guiding Question

AI tools can generate network advice in seconds — but how do you know if that advice is actually good?

Part 1 — Evaluate the AI

Below are three real-sounding requests someone made to an AI assistant, and the advice it gave back. For each one, decide: is this good advice for the situation described? What's right, what's wrong, and why?

Suggestion A

🤖 AI Network Assistant
Prompt: "How should I set up my home network?"
For a robust home network, I recommend: a 48-port rack-mount enterprise switch, three separate access points each with independent VLAN controllers, and a dedicated hardware firewall appliance. This setup will handle any number of devices with maximum reliability.

Context: a household of 4 people with about 10 devices total.

Concept: Judging AI Network Advice

  • Vague prompts tend to produce impractical or overly complex recommendations — the AI has no idea about budget, scale, or actual need, so it often defaults to "more is better."
  • AI suggestions can be technically flawed in ways that are easy to miss if you don't already know the underlying rules — like an IP address range that's mathematically invalid (an octet can't exceed 255).
  • Some suggestions are technically correct but a poor fit for the actual scenario — a real technology, used the wrong way for the situation described.
  • Good evaluation checks: does this match the actual number of users/devices? Is it realistic for the budget and skill level involved? Is it technically accurate? Does it fit the specific performance or coverage need described?

Vocabulary

  • Prompt — the request or question given to an AI tool; vague prompts tend to produce vague or unrealistic answers.
  • Media server — a device on a network used to store shared files, stream content, or host multiplayer games for other devices on that network.
  • Local file share — a folder on one device made accessible to other devices on the same network.

Part 2 — Hands-On: Set Up a Local File Share

A media server is really just a device that shares files, streams, or hosts something for other devices on the network. Today you'll configure the simplest version of that: a shared folder on your Server 2022 VM.

  1. Launch your Server 2022 VM (the one you used for the Filius labs).
  2. Create a new folder on the desktop or in a convenient location. Name it SharedMedia.
  3. Right-click the folder → Properties → Sharing tab → Advanced Sharing.
  4. Check Share this folder, then click Permissions and confirm at least Read access is allowed.
  5. Click Apply, then note the network path shown (it will look like \\SERVERNAME\SharedMedia).
